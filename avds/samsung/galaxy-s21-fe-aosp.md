# Galaxy S21 FE — AOSP AVD

Reference recipe for creating a Galaxy S21 FE-shaped Android Virtual Device.

- Hardware profile: `../../hardware-profiles/samsung/galaxy_s21_fe.xml`
- System image: Android AOSP / Google APIs / Google Play (select an installed compatible image)
- Display: 6.4-inch, 1080×2400
- Skin: Samsung Galaxy S21 FE emulator skin, when available
- Architecture: use the architecture supported by the selected system image

> This is a reference recipe, not a bundled `.avd` snapshot or Samsung system image.
