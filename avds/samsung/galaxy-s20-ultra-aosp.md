# Galaxy S20 Ultra — AOSP AVD

Reference recipe for creating a Galaxy S20 Ultra-shaped Android Virtual Device.

- Hardware profile: `../../hardware-profiles/samsung/galaxy_s20_ultra.xml`
- System image: Android AOSP / Google APIs / Google Play (select an installed compatible image)
- Display: 6.9-inch, 1440×3200
- Skin: Samsung Galaxy S20 Ultra emulator skin, when available
- Architecture: arm64-v8a

> This is a reference recipe, not a bundled `.avd` snapshot or Samsung system image.
