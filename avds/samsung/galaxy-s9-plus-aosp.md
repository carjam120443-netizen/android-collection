# Samsung Galaxy S9+ AVD

Reference AVD recipe for a Samsung Galaxy S9+-style Android emulator.

- Hardware profile: `../../hardware-profiles/samsung/galaxy_s9_plus.xml`
- System image: Android AOSP / Google APIs / Google Play — select an installed compatible image
- Display: 6.2-inch, 1440×2960
- Skin: Samsung Galaxy S9+ emulator skin, when available
- Architecture: use the architecture supported by the selected system image

This is a reference recipe, not a bundled `.avd` snapshot or Samsung system image. Samsung skins change the emulator appearance and controls; they do not provide One UI.
