# Galaxy S7 — AOSP AVD

Reference recipe for creating a Galaxy S7-shaped Android Virtual Device.

- Hardware profile: `../../hardware-profiles/samsung/galaxy_s7.xml`
- System image: Android AOSP / Google APIs / Google Play (select an installed compatible image)
- Display: 5.1-inch, 1440×2560
- Skin: Samsung Galaxy S7 emulator skin, when available
- Architecture: use the architecture supported by the selected system image

> This is a reference recipe, not a bundled `.avd` snapshot or Samsung system image.
