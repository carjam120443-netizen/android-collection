# Samsung Galaxy S20+ AVD

Reference AVD recipe for a Samsung Galaxy S20+-style Android emulator.

- Hardware profile: planned profile `../../hardware-profiles/samsung/galaxy_s20_plus.xml`
- System image: Android AOSP / Google APIs / Google Play — select an installed compatible image
- Display: 6.7-inch, 1440×3200
- Skin: Samsung Galaxy S20+ emulator skin, when available
- Architecture: use the architecture supported by the selected system image

This recipe documents the target device configuration. The referenced hardware profile should be added and verified before treating this recipe as directly importable.
