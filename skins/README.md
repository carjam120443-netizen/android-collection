# Emulator skins

## Samsung

Use the official Samsung Galaxy Emulator Skin downloads:

https://developer.samsung.com/galaxy-emulator-skin

Samsung's guide explains extracting a downloaded skin and selecting it from Android Studio Device Manager.

## Community

- Jiff21/AVD-devices includes a `Skins/` directory: https://github.com/Jiff21/AVD-devices/tree/master/Skins
- React-Native-Nation includes skins alongside its hardware profiles: https://github.com/React-Native-Nation/Hardware-Profiles-For-Android-Studio/tree/master/skins

Skins are kept as external downloads instead of being mirrored here when redistribution rights are unclear.
